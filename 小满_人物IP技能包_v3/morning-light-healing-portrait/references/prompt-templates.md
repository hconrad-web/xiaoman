# 提示词模板与参数

## 通用参数

| 项 | 值 |
|---|---|
| 画幅 / 像素 | 4:5 → 1024×1280；3:4 → 1024×1365；半身可 1080×1350 |
| 镜头 | 手机前置等效 24–26mm，f/1.8–2.2，距离 40–50cm |
| 色温 | 4800–5200K 暖调高调 |
| 色板 | 奶油白 `#F2EBDD`、燕麦 `#D8C6B0`、暖木 `#A8845F`、浅灰绿 `#C6CFC6` |
| 人物占幅 | 60%–85% |

带身份生成时统一句式：图1（母版）提供脸型、五官比例、发际线与年龄感；仅改变姿势、服装、光线与场景。

## 模板 A｜床上托腮（主力款）

> 竖幅近景人像。24–27 岁东亚女性坐在床上，靠着一只被压出凹陷的枕头，右手手背贴着脸颊、手指自然微屈托腮，手肘撑在被子上形成放松的三角，身体略微侧向镜头，头轻微低一点后抬眼直视镜头，嘴角只有一点点自然的松弛。蓬松微乱的自然黑长发垂过肩，几缕碎发穿过脸颊。穿奶油白棉麻睡衣，细条纹肌理、袖口有深色滚边，领口松开一点，布料有真实睡过的褶皱。窗外早晨的自然光从她右后方低角度打进来，形成发丝边缘的金色透光感，脸颊一侧有暖光斑和柔和的明暗过渡，被子和枕头上有一块被照亮的暖白色高光，暗部不黑，整体高调低对比。背景是浅灰白卧室墙面、木色矮柜、墙上几张小照片、一瓶白色花束，轻度虚化不抢脸。皮肤保留可见毛孔、微弱雀斑、鼻翼一点自然的红，轻微噪点与手机镜头的自然景深，不做磨皮和锐化。画面里没有文字、水印、标志。

## 模板 B｜侧躺回眸

> 竖幅半身。24–27 岁东亚女性侧躺在奶油白被褥里，被子堆到腰际、盖住一侧手臂，头枕在弯起的手肘上回眸看向镜头，另一只手轻搭在被角上。自然黑长发散在枕头上、被光照到一侧泛暖金色。穿浅灰绿棉质家居衣，肩线自然露出。晨光从头顶后方偏右掠进来，被褥褶皱上有明暗交替的暖高光，脸只被柔和的反射光打亮，安静、刚醒的状态。皮肤质感真实、有细微纹理与轻微油光，手机拍摄的自然噪点。背景留白为主，只见到床边一角与窗帘边缘，虚化。画面无文字。

## 模板 C｜飘窗抱膝

> 竖幅中近景。24–27 岁东亚女性抱膝坐在飘窗台，背靠窗框，下巴抵在膝盖上方的交叠手臂上，侧脸朝窗、眼睛半睁看向镜头方向，头发被窗外光透亮、有几缕落在肩前。穿燕麦色宽松针织开衫与白色棉质内搭，袖口卷起。窗外是虚化的绿植与楼景，晨光从侧后方穿过窗玻璃形成轮廓光，室内一侧靠浅色墙面反射补光，不补成平板亮。木色窗台上有马克杯与一本翻开的书。真实皮肤、轻微噪点、自然景深。画面无文字。

## 模板 D｜床边梳头（动作款）

> 竖幅半身。24–27 岁东亚女性坐在床沿，身体前倾，一只手手指插进头发里把一侧长发撩到耳后，另一只手放在膝上，视线低垂后抬眼看向镜头，头发因动作带起一点自然的散乱。穿奶油白宽松睡衣衬衫，扣子只系了两颗、下摆自然垂落。晨光从右后方进来，照亮头发与肩线，脸部主要靠环境反射光，明暗过渡柔和。背景是床边一角、木地板与浅色墙，虚化。皮肤真实、轻微噪点。画面无文字。

## 排除项写法

用自然语言写进提示词尾部，例如：

> 不要影楼布光和补光板打亮的平光，不要磨皮成塑料皮肤，不要放大眼睛削尖下巴的美颜，不要大笑露齿或嘟嘴卖萌，不要平整崭新的酒店式床品，不要高饱和滤镜和 HDR 感，不要过度锐化，画面里不要出现文字、水印、Logo。

## 批量出图节奏建议

1. 首图：模板 A（最能定调，也最容易判断人脸是否跑偏）。
2. 确认后按 2–4 张一组推进，每组至少换 2 项：景别、姿势、朝向、服装、光影角度。
3. 一组内保持光线方向一致（同一次早晨、同一扇窗），跨组才换光线角度。
