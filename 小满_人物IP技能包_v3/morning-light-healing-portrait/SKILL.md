# 晨光卧室治愈系人像

## 这套图长什么样

三件事同时成立，才是这个配方：**早晨窗光从侧后方逆着打进来**、**真实使用中皱着的奶油白床品**、**人物离镜头很近、手托着脸看镜头**。缺任一项，就变成普通美女照或影楼写真，不是这个风格。

判断标准：缩到手机缩略图大小看，要像"早上随手发给你的自拍"，不像"摄影师棚拍的写真"。

## 一、人物身份（不可漂移）

1. **优先沿用已有母版。** 若项目在跑某个固定 IP（例如"小满"人物设定），先读取该 IP 设定并取其**标准参考图**，用 `image_edit` 实传母版作为图1身份输入，本 skill 只负责场景、光线、服装、动作层。禁止仅凭文字重述人物，否则每张脸都不一样。
2. **无母版时用默认新人设。** 24–27 岁东亚女性，自然黑长发（蓬松微乱、有碎发穿过脸颊），清秀耐看而非惊艳型，鹅蛋或偏圆脸，杏眼、自然双眼皮、鼻头略圆、唇形偏薄；素颜或极薄妆感。
3. **固定锚点**：脸型、五官比例、眼型、鼻唇形状、发际线、年龄感。换场景、换衣服、换姿势都不动这些。
4. 参考图只提供**光线、构图、材质、姿势**信息，不得复制参考图中具体人的面部身份。

## 二、光线配方（本 skill 的核心）

- 主光：窗外早晨自然光，从人物**侧后方 45°–135°** 打进来，形成发丝金边与脸颊一侧的柔和明暗过渡。
- 色温偏暖 4800–5200K；高调（high-key）、低对比，阴影干净偏暖不偏灰。
- 光比 1:2 到 1:2.5：暗侧仍能看清皮肤与五官，不做死黑。
- 允许并鼓励：脸颊上一小块暖光斑、枕头上被照亮的高光块、逆光下透光的碎发。
- 禁止：柔光箱/环形灯正打、闪光灯硬光、反光板把暗侧补平、人造聚光灯效、HDR 式全图均匀亮。

## 三、场景与床品

固定场景族（卧室/飘窗，现实生活房间，不是样板间）：

- 床上：侧躺靠枕、被子堆到腰、下巴埋进被角。
- 飘窗：抱膝坐、靠窗框、窗外绿植或楼景虚化。
- 床边：坐床沿梳头、低头系睡衣扣子。

背景允许真实生活痕迹：墙上一排小照片、白色花束、护肤瓶、木柜、天花板出风口、窗帘一角。少量、低对比、轻度虚化，不抢脸。

**床品必须"用过"**：皱褶、压痕、垂坠的被角、枕头凹陷。禁止全新平整、酒店式方角铺床。

## 四、服装

奶油白、燕麦、浅灰绿为主的棉麻/针织家居服：

- 奶油白棉麻睡衣（细条纹肌理、深色滚边袖口）、宽松针织开衫、白衬衫当睡衣、浅灰绿棉质内搭。
- 允许轻微褶皱、露出的肩线、松开的领口、卷起的袖口。
- 禁止：亮片、大面积 logo、高饱和色、情趣化蕾丝、明显品牌标识、成套崭新睡衣广告感。

## 五、动作与表情

主导姿势是**手托脸**：手背或掌心贴脸颊，手指自然微屈，手肘撑在枕头或被子上，手臂形成放松的三角。其他可用：

- 手指插进头发里、撩起一侧头发、整理耳后碎发
- 半眯眼刚醒、下巴抵在交叠的手臂上、侧躺回眸
- 抿嘴轻微笑、视线直视镜头、呼吸放松的安静状态

表情要求：**眼睛有神但不瞪、嘴角有极小的弧度**。禁止大笑露齿、嘟嘴、眯眼卖萌、用力挑眉等网红表情。

## 六、镜头与画质

- 手机前置镜头语言：等效 24–26mm，f/1.8–2.2，拍摄距离 40–50cm，人物占画面 60%–85%。
- 画幅默认 4:5 或 3:4 竖幅：特写用 4:5，半身可用 3:4。像素 1024×1280 或 1080×1350。
- 机位略高于视平线、轻微俯拍；允许一点点倾斜，不做精确对称。
- 质感：轻微噪点、自然的边缘轻微畸变、真实景深虚化。皮肤保留毛孔、细碎雀斑、鼻翼微红、眼下淡青。
- 禁止：塑料磨皮、过度锐化、强滤镜、明显美颜瘦脸大眼、AI 抛光感、画内文字与 Logo。

## 六点五、真实感优先于好看

用户明确反馈过"AI 感太强"，所以默认按**原相机直出**写提示词：

- 首句写清来源：`iPhone 前置原相机自拍` 或 `朋友用手机随手拍` + `未修图未滤镜`。
- 每张至少 3 项真实缺陷：T 区油光、小痣或陈旧痘印、鼻翼毛孔、唇部干纹、静电碎发贴脸、衣服压痕、环境杂物（充电线、半杯水、搭着的衣服）。
- 光线允许不完美：混合色温、白平衡偏移、额头小块过曝、下巴硬阴影。
- 画质允许不完美：高 ISO 噪点、高光溢出、轻微动态模糊、焦点没吃准。
- 禁用词：柔和光斑、完美对称、高级感、大片质感、影棚布光、时尚人像、匀净肌肤、精细发丝、唯美、精致妆容、柔焦、无瑕。

判断标准：缩到手机缩略图，3 秒内像"朋友发来的照片"，而不是"写真"。

## 七、批量一致性

- 每张都用**同一张已确认母版**作为身份输入，逐张独立调用，不用一次多结果代替多张。
- 每张只改 1–2 项（动作 / 场景 / 服装之一），配色职责与光线方向保持不变；同套图避免连续同一景别同一姿势。
- 首次建立母版后先展示确认，再产出衍生；母版未确认前不批量。

## 八、提示词写法

四套可直接用的模板与参数见 [references/prompt-templates.md](references/prompt-templates.md)。要点：

1. 按"场景 → 光线 → 姿势 → 服装 → 质感 → 排除项"顺序写，一段连贯自然语言。
2. 光线一定写明方向（右后方/侧后方）与来源（窗外早晨自然光）。
3. 质感段必须写清"可见毛孔、轻微噪点、不做磨皮"。
4. 排除项用自然语言拒绝，不堆砌否定词。
5. 涉及身份时只写"沿用图1人物的脸型、五官与发际线，仅改变姿势、服装与光线"，不复述五官细节。

风格光线参考图见 `assets/style-reference.png`：仅在需要校准光线方向与材质密度时作为参考传入，不用于生成该图中人物的脸。

## 九、交付

- 图片返回后立即用 `<RichMediaCard>{"refs":["真实资源引用"]}</RichMediaCard>` 逐张展示，不以文字描述代替展示。
- 每张说明本张变了什么、保留了什么，方便用户判断是否跑偏。
- 用户指出脸漂移时，回到母版重做，不靠文字描述"修脸"。
