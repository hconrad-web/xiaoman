# 去 AI 感 · 真实感配方

## 一、先认清 AI 感从哪来

| AI 感来源 | 真实照片里对应的是什么 |
|---|---|
| 皮肤均匀无瑕、像哑光塑料 | 油光（T 区、鼻头）、干纹、痘印、小痣、左右肤色不均、局部泛红 |
| 光线均匀柔和，像打了柔光罩 | 混合色温、白平衡偏移、额头小块过曝、下巴硬阴影、环境杂散反光 |
| 眼睛过亮、高光位置统一 | 眼神光来自手机屏幕/窗户，位置不对称；眼白偏黄不纯白 |
| 头发丝滑整齐、发缝规则 | 静电碎发、毛躁、被压扁的一侧、发缝歪、碎发横过嘴唇 |
| 构图居中干净、无杂物 | 边角有充电线、水杯、路人、衣架；画面略歪；头顶/下巴被切一点 |
| 景深过渡完美 | 焦点没吃准、前景手臂更虚、边缘轻微拖影 |
| 表情"中性美" | 微表情不对称：一边嘴角高、下颌放松、下颌线有肉 |
| 衣服褶皱规律、面料干净 | 压痕、起球、静电吸附、领口歪、下摆没束好 |
| 画质过于干净 | 高 ISO 噪点、高光边缘溢出、轻微动态模糊、锐化算法过头的边缘 |

**一句话判据**：把图缩到手机缩略图大小，3 秒内像不像“朋友发给你的照片”；像“写真”就是 AI 感没压下去。

## 二、拍摄设定（写进提示词，比形容词管用）

- 设备与来源：`iPhone 前置原相机自拍` / `朋友用 iPhone 随手拍` / `手机举高俯拍`，并写明**未修图未滤镜**。
- 距离与畸变：自拍 30–45cm，写明"额头与下巴有轻微广角变形"。
- 快门与噪点：写明"室内光线导致噪点明显""快门略慢、手部与发丝边缘发虚"。
- 白平衡：写明"室内暖灯与窗外光混色，白平衡不准，一侧偏暖一侧偏冷"。
- 景深：写明"焦点没完全吃准，前景比脸更虚"。

## 三、缺陷清单（每张至少放 3 项）

皮肤：T 区油光、下巴陈旧痘印、脸颊小痣、鼻翼毛孔、唇部干纹、肤色不均
头发：静电碎发贴脸、发缝可见、被压的乱翘、碎发横过嘴边
身体：下颌放松有肉、锁骨不明显、手臂有淡淡压痕
衣服：压痕、起球、领口歪、扣子没系全、静电吸附
环境：充电线、半杯水、搭着的衣服、路人虚影、水渍反光、窗帘一角
表情：一边嘴角高、眨眼瞬间、说话中途、刚抬眼的瞬间

## 四、禁止出现的词（这些词一出，图就假）

柔和光斑、完美对称、高级感、大片质感、影棚布光、时尚人像、匀净肌肤、精细发丝、唯美、精致妆容、柔焦、通透明亮、无瑕。

## 五、提示词骨架

1. **设备句**：`用 iPhone 前置原相机随手自拍，未修图未滤镜。`
2. **距离与姿势句**：`脸距镜头很近，额头与下巴有轻微广角变形，头略偏，正在抬眼看手机。`
3. **缺陷句**：`T 区有油光反射，脸颊一颗小痣、下巴一点陈旧痘印，鼻翼毛孔清楚，唇部略干有细纹。`
4. **环境句**：`被子乱堆、枕边有充电线与喝剩的水杯、半件衣服搭在床上。`
5. **光线句**：`窗外晨光与你开的暖黄台灯混色，色温不统一，额头有过曝小块。`
6. **画质句**：`噪点明显、轻微动态模糊、高光溢出，景深没吃准。`
7. **排除句**：`不要商业摄影感、不要时尚大片、不要影棚光、不要磨皮、不要对称完美。`

## 六、三条硬规则

- **先写设备与缺陷，再谈审美。** 形容词堆不出真实感，拍摄设定能。
- **一张里不要超过 5 项缺陷**，否则变成刻意丑化，也不像真的。
- **人物身份仍走母版。** 加缺陷不等于改脸：痣、痘印可加，脸型五官不能动。
