# Look 卡库与换装提示词

## Look 卡字段说明

`编号 / 用途 / 上装 / 下装 / 外层 / 鞋包 / 配饰 / 发型 / 妆容 / 色板 / 场景光线`

换装时只动这组字段，身份描述一律不重写。

---

## L1 居家基础（默认基准造型）

- 用途：日常内容、开箱、生活流
- 上装：奶油白粗针织开衫，内搭浅灰绿棉质 T
- 下装：燕麦色宽松棉麻长裤
- 外层：无
- 鞋包：无／赤足或浅灰棉袜
- 配饰：一只细银戒、无耳饰
- 发型：自然披发（基准）
- 妆容：素颜
- 色板：奶油白 `#F2EBDD`、浅灰绿 `#C6CFC6`、燕麦 `#D8C6B0`
- 场景：卧室窗边、沙发、书桌，自然散射光

## L2 通勤通学

- 用途：上班/地铁/写字楼、职场叙事
- 上装：白衬衫（棉或府绸，微宽松），内搭薄针织
- 下装：深灰直筒西裤
- 外层：燕麦色长风衣或驼色大衣
- 鞋包：黑色乐福鞋、深棕托特包
- 配饰：细表带手表、小耳圈
- 发型：低马尾或半扎
- 妆容：日常
- 色板：米白 `#F2EDE6`、烟灰 `#8C8880`、驼 `#B08A63`
- 场景：地铁车厢、写字楼玻璃幕墙前、街边红绿灯，侧光或阴天散射

## L3 文艺周末

- 用途：书店/展览/咖啡馆、慢生活内容
- 上装：米白棉麻长裙（及踝）或针织开衫＋吊带长裙
- 下装：裙
- 外层：薄羊毛开衫搭肩
- 鞋包：棕色平底穆勒鞋、帆布小挎包
- 配饰：细金链、布质发圈
- 发型：半扎或低盘发
- 妆容：日常
- 色板：米白、暖棕 `#A8845F`、灰绿
- 场景：咖啡馆靠窗位、书店书架前、展馆白墙，暖色窗光

## L4 秋冬厚装

- 用途：秋冬季节内容、围巾造型
- 上装：奶白高领毛衣
- 下装：深棕或炭灰阔腿裤
- 外层：驼色长羊毛大衣
- 鞋包：短靴、皮质单肩包
- 配饰：羊绒围巾（浅驼/灰）、针织帽（可选）
- 发型：披发塞进围巾里，或低马尾
- 妆容：日常
- 色板：驼 `#B08A63`、奶白、炭灰 `#4A4744`
- 场景：落叶街道、咖啡馆门口、地铁出口，低角度暖阳

## L5 运动休闲

- 用途：晨跑/散步/日常随手
- 上装：灰绿色运动卫衣或无袖背心
- 下装：黑色紧身运动裤
- 外层：无
- 鞋包：白色跑鞋、小号腰包
- 配饰：运动手表、发带
- 发型：高马尾（须保留同一发际线）
- 妆容：素颜
- 色板：灰绿、黑、白
- 场景：清晨公园、跑道、江边，逆光或侧逆光

## L6 轻正式

- 用途：发布会/访谈/见客户
- 上装：黑色或深灰西装外套，内搭丝质衬衫
- 下装：同色系直筒裤
- 外层：—
- 鞋包：细跟或方头中跟、硬挺小方包
- 配饰：细链、耳钉
- 发型：低盘发或利落低马尾
- 妆容：轻正式
- 色板：黑 `#1E1D1C`、米白、一点点暖金
- 场景：纯色墙面、酒店大堂、会议室，硬朗侧光但保留面部柔过渡

## 发型分支表

| 分支 | 允许 | 注意 |
|---|---|---|
| 自然披发 | ✅ 基准 | 碎发可穿过脸颊，别遮眼 |
| 低马尾 | ✅ | 额前露出面积与母版一致 |
| 半扎 | ✅ | 两侧留少量碎发，不改鬓角形状 |
| 低盘发 | ✅ | 耳朵可露出，耳形与母版一致 |
| 齐肩微卷 | ✅（需登记） | 长度变化会改整体年龄观感，仅用于特定系列 |
| 齐刘海 / 厚斜分 | ❌ | 遮住发际线与额头比例，最容易换脸 |
| 大背头 / 全梳起 | ❌ | 暴露颅顶比例差异，不做 |
| 明显染发（金/粉/红） | ❌ | 改色板身份，仅在设计过的分支内允许 |

## 换装提示词句式

**首句固定（不要改）：**

> 沿用图1、图2 人物的脸型、五官比例、眼型、鼻唇形状、发际线、年龄感、体型与头身比，只改变服装、发型、妆容浓度、姿势与场景。

**中段按 Look 卡填：**

> 穿{上装}，{下装}，{外层}，{鞋包}，{配饰}。发型为{发型}。妆容{浓度}，只调整浓淡，不改五官形状。整体色板为{色板}。

**尾段按场景光线填：**

> 场景为{场景}，{光线描述}，真实手机摄影质感，可见毛孔、轻微噪点与自然景深，不做磨皮与锐化。

**排除项固定：**

> 不要放大眼睛、削尖下巴、缩窄鼻翼，不要网红浓妆与滤镜，不要改变发际线，不要画面文字与水印。

## 变形与体型

- 全身或七分身时，必须在提示词里补一句"身高感{身高}、肩线与头身比与图1一致"，否则模型会顺手拉长腿或缩肩。
- 服装廓形可改（宽松/合身/廓形大衣），但**肩宽、颈长、腰线位置**不动。
- 鞋跟高度变化会改站姿重心，换高跟时一并写明"重心不变，仅脚踝角度变化"。
