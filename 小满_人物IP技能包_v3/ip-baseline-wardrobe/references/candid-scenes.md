# 场景配方库（真实抓拍档）

基准锚点：`assets/realism-anchor-approved.png`（街头逆光回头，发丝横过脸、背景人流与电动车拖影）。新图以它为“真实度”参照，不以它为身份来源——身份仍走 `baseline-master-01/02/03`。

每条配方都按「拍摄来源 → 姿势 → 服装 → 光线 → 环境 → 画质 → 排除」写。

## A. 地铁站台

- 来源：朋友站旁边用 iPhone 随手拍
- 姿势：刚低头看完手机、抬眼；肩微缩；一手捏手机贴胸口，一手提帆布包带
- 服装：深灰连帽卫衣＋黑直筒裤，帽子搭肩，随手低马尾（一侧碎发落下）
- 光线：顶上冷白灯管＋进站列车暖色车灯，混合色温，下巴与锁骨硬阴影
- 环境：候车人流、进站列车拉出的虚影、玻璃门反光、构图歪、头顶被切
- 画质：噪点明显、轻微手抖、高光边缘溢出

## B. 便利店门口（夜）

- 来源：晚上随手拍
- 姿势：拎塑料袋＋关东煮往外走，头往回看，表情松散
- 服装：奶油白针织开衫＋直筒牛仔裤，夜风吹乱的头发
- 光线：灯箱冷白＋路灯暖黄，一侧过白一侧落阴影，额头鼻梁强高光
- 环境：玻璃门内货架与人影反射，画面下角有手臂挡到一点
- 画质：夜景噪点重、白平衡偏黄、边缘拖影

## C. 咖啡馆窗前

- 来源：坐对面的人用 iPhone 拍
- 姿势：手背托腮，前伏桌面，视线在窗外不看镜头
- 服装：米白棉质衬衫，袖口卷到手肘
- 光线：午后斜光打桌角，玻璃反射把脸分成冷暖两半
- 环境：窗外虚化车流人影、桌上没喝完的咖啡与手机
- 画质：白平衡偏黄、对焦略偏后、边缘轻微拖影
- ⚠️ 反射风险：玻璃倒影容易与真脸轮廓对不齐（AI 破绽）。处理方式是把倒影压暗、虚化、错位，不追求清晰反射

## D. 楼道回家

- 来源：被叫住时的随手拍
- 姿势：半蹲在帆布包里翻钥匙，头发垂下来遮住一侧脸，抬头被打断，表情有点疲
- 服装：燕麦色家居服＋拖鞋，衣领歪、袖口水渍
- 光线：声控灯偏绿的弱散光，下巴与眼窝重阴影
- 环境：老旧墙面污渍、小区告示贴纸、楼梯扶手、邻居家门
- 画质：噪点重、画面偏暗偏绿、对焦略虚、构图歪
