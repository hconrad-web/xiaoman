# 人物基调与换装系统

## 这个 skill 解决什么

不加约束地"换个衣服"，模型会顺手把脸、年龄、气质一起换掉——因为服装、光线、景别都在变，模型会重新"想象"一个人。

所以这里把人物拆成三层，只有下面两层允许改：

| 层 | 内容 | 权限 |
|---|---|---|
| **不变层**（身份锚点） | 脸型、五官比例、眼型、鼻唇形状、发际线、年龄感、体型骨架、肤质基线、气质与眼神基调 | 一律不动 |
| **半可变层**（造型） | 发型（在登记的造型分支内）、妆容浓度、眼镜/耳饰/表/指甲、发色（仅登记在案的） | 每次只改 1–2 项 |
| **可变层**（外观） | 服装、鞋、包、场景、光线、姿势、景别 | 按 Look 卡自由切换 |

## 一、先定基调（只做一次）

### 1.1 基调文案

在 SKILL 里或对话中固定一段"人设描述"，作为唯一事实来源。字段必须齐全：

- 年龄与身份感（如 24 岁、刚工作两年的城市女性）
- 脸型与比例（鹅蛋偏圆、中庭略短、下颌线柔和）
- 五官（杏眼、自然双眼皮、鼻头略圆、唇形偏薄且唇峰不明显、眉形平缓）
- 发际线与发质（自然发际线、少量碎发、黑色带一点冷调、发量偏多、自然微卷）
- 肤质基线（偏干、可见毛孔、鼻翼微红、眼下有淡青）
- 体型（身高感、肩线、颈部长度、骨架偏小）
- 气质与眼神（安静、有内里力量、眼神不飘、不甜腻）
- **默认造型**（基础发型＋基础服装＋基础色板，一般是奶油白针织＋自然披发）

### 1.2 母版组（必须三张，缺一张后面一定漂）

用 `image_edit` 或 `image_gen` 生成，同一轮、同一光线、同一素颜状态：

1. **正面半身**：正对镜头、中性表情、自然光，用于校准脸宽比与五官位置。
2. **45° 侧脸**：看清鼻梁、颧骨、下颌线转折，用于校准侧脸。
3. **全身或七分身**：站姿自然、简单服装，用于校准身高感、肩线、头身比。

母版要求：无妆或极薄妆、头发不遮挡五官、无滤镜、无文字。生成后逐张展示，**用户确认后才算冻结**；未确认前不做任何换装衍生。

### 2.1 每次生成的动作

1. 读取已冻结的基调与母版三张。
2. `image_edit` 实传母版（正面为主，侧脸为辅），提示词首句固定为：
   > 沿用图1、图2 人物的脸型、五官比例、眼型、鼻唇形状、发际线、年龄感与体型，只改变服装、发型、妆容浓度、场景与姿势。
3. 一次只改半可变层的 1–2 项 + 可变层的若干项。
4. 逐张独立调用，不用一次多结果凑多张。

### 2.2 Look 卡

每套造型写成一张卡再生成，字段固定：`编号 / 场景用途 / 上装 / 下装或裙 / 外层 / 鞋包 / 配饰 / 发型 / 妆容浓度 / 色板 / 光线与场景`。六套现成 Look 与发型分支见 [references/looks.md](references/looks.md)。

### 2.3 发型分支（登记制）

发型是唯一"改动幅度越大越容易换脸"的项。只允许在登记过的分支里切换：

- 自然披发（基准）→ 低马尾 → 半扎 → 低盘发 → 齐肩微卷
- 换分支时，**额头露出面积与发际线形状必须与母版一致**；刘海、厚重斜分、大背头默认不允许，会遮住身份特征。

### 2.4 妆容浓度三档

- `素颜`：零妆或极薄底妆，最接近母版，用于真实感内容。
- `日常`：薄底＋淡唇＋自然眉，唇色饱和度略高。
- `轻正式`：可见眼影与唇形轮廓，但仍不做网红大眼与锥子脸。

只调浓淡，不改五官形状。

## 二点五、真实感（默认开启，优先级高于美观）

用户反馈过"AI 感太强"。凡是人像出图，**默认按原相机直出写提示词**，细则见 [references/realism.md](references/realism.md)。

三条底线：

- 提示词第一句写清拍摄来源（`iPhone 前置原相机自拍` / `朋友用手机随手拍`）+ `未修图未滤镜`，不要写"摄影""大片""影棚"。
- 每张至少放 3 项真实缺陷：T 区油光、小痣或陈旧痘印、鼻翼毛孔、唇部干纹、静电碎发、衣服压痕、环境杂物（充电线、水杯、路人虚影）。
- 加缺陷不等于改脸：痣、痘印、油光可以加，脸型五官发际线不能动。

禁用词清单（出现即视为不合格）：柔和光斑、完美对称、高级感、大片质感、影棚布光、时尚人像、匀净肌肤、精细发丝、唯美、精致妆容、柔焦、无瑕。

**真实度基准**：以 `assets/realism-anchor-approved.png`（街头逆光回头）为用户已认可的基准档，新图只对标它的真实度，不从它取脸。四个已验收场景配方（地铁站台 / 便利店夜 / 咖啡馆窗前 / 楼道回家）见 [references/candid-scenes.md](references/candid-scenes.md)。

## 三、漂移检查（每张交付前在内部过一遍）

对照母版逐项看，任一项明显不同就回到母版重做，不要靠文字"修"：

1. 脸宽比（颧骨到下颌的横向宽度）
2. 眼距与眼形（是否被拉大、被拉长）
3. 鼻梁长度与鼻头大小
4. 唇厚与唇峰形状（是否被画成标准"网红唇"）
5. 发际线高度与形状
6. 年龄感（是否变年轻/变老 3 岁以上）
7. 头身比与肩宽（全身/七分身必查）

另加一项真实感检查：脸部是否有 3 项以上缺陷（油光、痣、毛孔、唇纹），长图里是否完全找不到噪点与硬阴影——都没有就说明磨皮过头了，重出。

## 四、禁止事项

- 禁止只凭文字描述重建人物，必须实际传入母版图。
- 禁止在同一套里连续换脸式改妆容浓度（一套内固定一档）。
- 禁止把人物改成网红脸：放大眼睛、削尖下巴、缩窄鼻翼、加高鼻梁、唇部丰盈。
- 禁止大幅改发色与发型长度而不登记分支。
- 禁止用滤镜、强磨皮、美颜相机效果掩盖身份差异。
- 禁止画内出现文字、水印、品牌 Logo。

## 五、与其他 skill 的关系

三层可叠加，各管一层，不互相替代：

- `ip-baseline-wardrobe`（本 skill）：管**是谁**——脸、体型、气质、发型分支。
- 场景/光线类 skill（如 `morning-light-healing-portrait`）：管**在什么光线下、什么房间里、什么姿势**。
- 内容/文案类需求：管**这张图要承载什么信息**。

叠加顺序：先取母版 → 按 Look 卡换装 → 再套场景光线参数 → 生成。

## 六、交付

- 母版组、每张换装图都用 `<RichMediaCard>{"refs":["真实资源引用"]}</RichMediaCard>` 逐张展示，不以文字代替。
